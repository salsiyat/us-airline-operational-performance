# Download Guide – Airline Financial Data (Form 41)

This folder stores quarterly airline financial summary data.

---

## Source
BTS Form 41 – Schedule P-1.2  
https://www.transtats.bts.gov/Tables.asp?QO_VQ=EFD

---

## Steps
1. Open the link
2. Select **Air Carrier Financial Reports (Form 41)**
3. Choose:
   - Schedule: P-1.2 Statement of Operations
   - Carriers: All
   - Years: 2022, 2023, 2024
   - Period: Quarterly
4. Export format: CSV
5. Save as: `Airline_Financial_2022_2024.csv`


## Expected Output
- ~120 rows
