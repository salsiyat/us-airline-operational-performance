## Dataset 5: Weather Data (Contextual)

**Source:**  
NOAA Climate Data Online  
https://www.ncei.noaa.gov/cdo-web/search

**Recommended Airports:**  
Top 10–15 major U.S. hubs (ATL, DFW, ORD, LAX, DEN, etc.)

**Steps**
1. Search by airport or city
2. Date range: 01/01/2022 – 12/31/2024
3. Select data:
   - Temperature
   - Precipitation
   - Wind Speed
   - Visibility
   - Snow/Ice
4. Download CSV
5. Combine airports into one file if possible
6. Save as `Weather_All_Airports_2022_2024.csv`
