# Download Guide – Weather Data

This folder stores historical weather data for major U.S. airports.

---

## Source (Recommended – Easier)
Visual Crossing Weather  
https://www.visualcrossing.com/weather-data

---

## Steps
1. Open the link
2. Search by airport city or coordinates
3. Date range:
   - 01/01/2022 to 12/31/2024
4. Select data:
   - Temperature
   - Precipitation
   - Wind speed
   - Visibility
   - Snow / severe weather
5. Export as CSV
6. Repeat for top 10–15 major airports
7. Combine into one file
8. Save as: `Weather_All_Airports_2022_2024.csv`
